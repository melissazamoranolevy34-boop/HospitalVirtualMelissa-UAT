# CU003 Gestión de Laboratorio

## Objetivo

Gestionar la solicitud, procesamiento y entrega de resultados de exámenes clínicos.

## Flujo

1. Médico solicita examen.
2. Se genera orden de laboratorio.
3. Laboratorio recibe solicitud.
4. Se procesa muestra.
5. Se registran resultados.
6. Resultados disponibles para el médico.

## Resultado Esperado

Examen procesado correctamente y resultado disponible en el sistema.
